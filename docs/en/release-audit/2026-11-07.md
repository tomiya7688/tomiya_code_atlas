## Purpose and scope

This record identifies distribution artifacts whose provenance can or cannot be verified before v1.0.0. It reflects GitHub API responses inspected on 2026-11-07.

The GitHub Releases API returned zero releases and no Release assets. I listed all 32 main-branch runs for `.github/workflows/go-exe.yml` and fetched each run's Actions artifact list. They were created between 2026-10-02 and 2026-11-07 and contained 33 retained artifacts. Every artifact reported `expired: false`.

This snapshot covers only the main-branch Go EXE workflow. Pull request runs were excluded after confirming that the workflow does not upload distribution artifacts for those events. Push runs on non-main branches and artifacts from the older `.github/workflows/build.yml` remain unaudited. Therefore, the full Issue #255 historical audit is incomplete.
