# Go版GUIの使い方

英語版: [GUI Usage](../en/GUI-Usage.md)

Go版GUIは、Windows利用者が解析対象、作成する図、保存先を選び、実行状況・診断・生成結果を一画面で確認するための画面です。GUI本体はGoで動作するため、利用者はPythonをインストールする必要がありません。各言語の解析補助プログラムは、配布フォルダー内の `backends/` から起動します。

Windows配布物の `tomiya-code-atlas.exe` をダブルクリックすると起動します。開発者はリポジトリのルートで `run_dist.bat` を引数なしで実行して起動できます。

## 解析を実行する

1. 「ファイルを選ぶ」または「フォルダーを選ぶ」を押し、解析するソースファイルかプロジェクトフォルダーを選択してください。パス欄へ直接入力することもできます。相対パスはアプリ起動時の作業フォルダーを基準にします。迷った場合は選択ボタンを使ってください。
2. 「作りたい図」で呼び出し図、クラス図の一方または両方にチェックしてください。Go版で現在利用できる図だけを表示します。
3. 保存先フォルダーを確認してください。初期値はホームフォルダー内の `Tomiya Code Atlas/atlas-output` です。「保存先を選ぶ」またはパス欄から変更できます。
4. 「解析を実行」を押してください。実行中は状態を表示します。完了すると生成したファイルのパスを一覧に表示し、失敗すると原因を「診断」に表示します。

キーボード操作も使えます。入力ファイルは `Alt+F`、入力フォルダーは `Alt+P`、保存先フォルダーは `Alt+O`、解析実行は `Alt+R` です。各ボタンにもキー操作を表示します。

## 現在の対応範囲

Go版GUIで作成できるのは、呼び出し図とクラス図のMarkdownファイルです。プロジェクトフォルダーを選ぶと、対応するソースファイルを下位フォルダーまで探し、各ファイルを対応する解析器へ渡します。ファイルを越えた名前・型の解決、コメント生成、その他の図、CI解析は移植中です。未対応の図は選択肢に表示しません。

CLIを使う場合は `tomiya-code-atlas-cli.exe` を実行するか、ルートの `run_dist.bat` にCLI引数を渡してください。CLIの詳しい使い方は[CLI利用ガイド](CLI利用ガイド.md)を参照してください。

開発者はリポジトリのルートで `build_exe.bat` を実行すると、GUI、CLI、解析補助プログラムをフォルダー形式の配布物としてビルドできます。

実画面での操作確認とGitHub配布物からの実行確認は、現在受け入れ確認中です。
