# クラス責務表

## 目標

各classの主要な責務を簡潔な表にします。

出力例:

```text
Class,Responsibility
Tomiya,Holds Tomiya parameters
```

## 解析

- 言語非依存modelからclass／type宣言を抽出する。
- class名、member、method、継承、依存関係、利用可能なcomment／docstringから責務を推論する。
- 決定的な構造上の事実と、推論した自然言語の責務説明を分ける。

## 出力

Markdown表示とCSV互換形式へのexportができる単純な表形式を優先します。
