# 機能仕様一覧

文書は必要な仕様だけを読み込めるよう、機能ごとに分けています。

## 必要なときに読む仕様

- コメント生成 → `コメント生成.md`
- UML／graph図の生成 → `図表生成.md`
- クラス責務表 → `クラス責務表.md`
- CI連携とcheck → `CI解析.md`
- 設計品質の評価 → `設計評価.md`

## Issue labelによる案内

`tools/next_issue.py` は、選択したGitHub Issueの `spec:*` labelを該当する最小限の仕様pathへ対応付け、そのpathを `.codex/next_issue.md` に出力します。

推奨label:

- `spec:comment-generator` → `コメント生成.md`
- `spec:class-diagram`、`spec:sequence-diagram`、`spec:call-graph`などdiagram label → `図表生成.md`
- `spec:class-responsibility-table` → `クラス責務表.md`
- `spec:ci-analyzer` → `CI解析.md`
- `spec:design-evaluation` → `設計評価.md`

実際に複数機能をまたぐ場合は複数の `spec:*` labelを付けられます。認識済みlabelがないIssueについては、必要最小限の実装fileだけを確認し、すべての仕様を読むよう求めません。

## Contextルール

repository rootの `AGENTS.md` を最初に読みます。その後、該当する仕様だけを確認します。複数仕様を読むのは責務を本当にまたぐ場合に限ります。

機能仕様の一節が大きくなった場合は、常時読み込む文書を肥大化させず、独立した仕様へ分割します。
