# コールグラフ生成器

コールグラフpipelineは言語adapterと `ModuleIR` を再利用します。

```text
Language Adapter -> ModuleIR -> CallGraph -> Generator -> Mermaid Renderer
```

初期Python対応では、直接のcaller／callee edge、fan-in／fan-out指標、root起点の深さ制限付き探索、高fan-in検出、cycle検出、Mermaid flowchart出力を提供します。ほかの言語adapterも同じ `ModuleIR` を渡すことで、graph解析やRendererを変更せずに利用できます。
