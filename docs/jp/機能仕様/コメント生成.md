# コメント生成

## 目標

programの動作を保ちながら、有用なsource code commentを自動追加します。

## 言語

初期対象: Python、GDScript、C#、Java。5番目の言語候補はRubyまたはCです。

## 振る舞い

- Language Adapter層を使ってsourceをparseする。
- module、class、method／function、分かりにくいbranch、重要なstate／data変換など、commentが有用な構造を特定する。
- 無関係なcodeを書き換えずにcommentを生成する。
- 可能な限り書式を保つ。
- comment挿入で実行可能な意味を変更しない。

## 解析境界

決定的な構造抽出は `Src/analyzers/` と `Src/languages/` が担います。自然言語comment生成にLLMを使う場合は決定的解析から経路を分け、可能な範囲でLLMなし運用を維持します。

## 出力

commentが挿入された変更後のsource code。
